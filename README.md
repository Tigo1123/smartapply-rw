# SmartApply RW

موقع عربي وإنجليزي لخدمات الطلاب في رواندا.

## التشغيل على جهازك

1. فك ضغط الملف وافتح المجلد في VS Code أو Codex.
2. تحتاج Node.js 20 أو أحدث.
3. شغّل `npm run dev` وافتح http://localhost:3000.
4. لا توجد مكتبات تحتاج إلى تنزيلها. ويمكن فتح dist/index.html مباشرة أو عبر Live Server.

## الملفات

- dist/index.html: الأقسام والنصوص الأساسية.
- dist/style.css: التصميم والهاتف.
- dist/app.js: اللغات والجامعات والتعليقات والتفاعلات.
- dist/assets/: الصور والشعار.
- AGENTS.md: تعليمات Codex الخاصة بالمشروع.

## GitHub وVercel

أنشئ مستودع GitHub ثم ارفع كامل محتويات هذا المجلد. اربط المستودع بمشروع Vercel. إعدادات النشر:
- Framework: Other
- Build command: npm run build
- Output directory: dist

ملف vercel.json يحدد الإعدادات. لم يتم إنشاء مستودع GitHub أو مشروع Vercel تلقائياً ضمن هذه النسخة.
بعد ربطهما، تؤدي التغييرات المرفوعة للفرع المخصص للنشر إلى تحديث الموقع وفق إعدادات Vercel.

## فحص المشروع

شغّل npm run check، ثم راجع العربية والإنجليزية والهاتف والكمبيوتر، قائمة التنقل وأسهم التعليقات وروابط واتساب والصور.
الموقع تعريفي مع استفسارات واتساب؛ لا يتضمن حسابات طلاب أو قاعدة بيانات أو دفعاً. التعليقات الحالية نماذج توضيحية.
